# AI 학습 기록 (개인 MVP)

유튜브에서 영상을 보면 **자동으로 기록**하고, **AI 관련 영상만** 골라 요약 · 용어 · 활용법 · 태그로 정리합니다.
태그/용어를 공유하는 영상끼리는 "연관 영상"으로 이어집니다.

```
[크롬 확장] 30초 이상 시청 감지 → 제목/채널/설명/자막 수집
      ↓ (localhost)
[서버] Claude 로 "AI 관련?" 판별 → 아니면 버림, 맞으면 요약/용어/활용법/태그 생성 → data/videos.json
      ↓
[대시보드 http://localhost:3000] 검색 · 태그 · 용어집 · 연관 영상
```

## 실행

1. API 키 준비: `cp .env.example .env` 후 `ANTHROPIC_API_KEY=` 에 키 입력
2. 서버 시작 (Node 22 이상, 설치할 패키지 없음)
   ```
   cd server && npm start
   ```
3. 크롬 → `chrome://extensions` → 개발자 모드 ON → "압축해제된 확장 프로그램을 로드합니다" → `extension/` 폴더 선택
4. 유튜브에서 AI 영상을 30초 이상 시청 → http://localhost:3000 에서 확인 (분석에 수 초 걸립니다)

## 알아둘 점

- **서버가 켜져 있을 때만 기록됩니다.** 꺼져 있으면 그 시청분은 저장되지 않습니다.
- 설치 **이후**의 시청만 기록됩니다. 과거 기록은 다음 단계(Google Takeout 가져오기)에서 채웁니다.
- 자막은 비공식 방식으로 가져오므로 실패할 수 있습니다. 실패하면 제목/설명만으로 판별·요약하고 대시보드에 "자막 없음"으로 표시합니다.
- 데이터는 내 PC(`server/data/`)에만 저장됩니다. 외부로 나가는 것은 분석을 위해 Claude API로 보내는 제목/설명/자막뿐입니다.
- AI와 무관하다고 판별된 영상은 자막 등 내용을 버리고 "제외" 건수만 남깁니다.
